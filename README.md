# Customer Segmentation Project

## Objective

To segment customers based on their age, annual income, and spending behavior using K-Means Clustering.

## Tools Used

* Python
* Pandas
* Matplotlib
* Scikit-Learn

## Dataset Features

* CustomerID
* Gender
* Age
* Annual_Income_LPA
* Spending_Score

## Algorithm

K-Means Clustering



## Conclusion

Customers were grouped into different segments based on their spending patterns and income. This helps businesses understand customer behavior and improve marketing strategies.
